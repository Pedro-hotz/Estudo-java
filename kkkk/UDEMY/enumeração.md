Enumeração é uma variável com possiveis valores atribuidos. Semelhante a uma "interface" em typeScript 


Criação 
    - A criação é basicamente apertar com o botão direito e apertar em new -> enum


Utilização 
    - Usa como valor de uma variável em outro file/classe


Conversão de String para Enum 
    OrderStatus os1 = OrderStatus.DELIVERED; 
    OrderStatus os2 = OrderStatus.valueOf("DELIVERED");
